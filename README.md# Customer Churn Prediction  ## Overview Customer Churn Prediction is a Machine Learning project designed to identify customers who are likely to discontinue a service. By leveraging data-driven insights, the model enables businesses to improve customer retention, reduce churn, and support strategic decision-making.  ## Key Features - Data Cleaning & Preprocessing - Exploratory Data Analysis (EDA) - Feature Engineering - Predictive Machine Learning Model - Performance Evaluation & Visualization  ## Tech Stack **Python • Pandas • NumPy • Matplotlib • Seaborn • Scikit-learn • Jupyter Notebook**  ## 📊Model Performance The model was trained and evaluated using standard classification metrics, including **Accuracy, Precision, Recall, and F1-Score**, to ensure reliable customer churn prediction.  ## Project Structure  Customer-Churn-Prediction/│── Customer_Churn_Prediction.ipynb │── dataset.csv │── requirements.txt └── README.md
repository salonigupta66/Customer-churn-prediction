# Customer Churn Prediction

## Overview
Customer Churn Prediction is a Machine Learning project designed to identify customers who are likely to discontinue a service. By leveraging data-driven insights, the model enables businesses to improve customer retention, reduce churn, and support strategic decision-making.

## Key Features
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Predictive Machine Learning Model
- Performance Evaluation & Visualization

## Tech Stack
**Python • Pandas • NumPy • Matplotlib • Seaborn • Scikit-learn • Jupyter Notebook**

## 📊Model Performance
The model was trained and evaluated using standard classification metrics, including **Accuracy, Precision, Recall, and F1-Score**, to ensure reliable customer churn prediction.
